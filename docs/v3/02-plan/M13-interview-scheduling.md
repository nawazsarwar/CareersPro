# M13 — Interview Scheduling

**Wave:** 8 · **Scope:** **v1-partial** *(video interviews and travel-allowance claims deferred to v2)*
**Depends on:** M21, M19, M34

## 1. Purpose and statutory basis

Schedule interview slots, issue letters, and record attendance.

| Obligation | Source |
|---|---|
| **The selection process must be completed on the day of the committee meeting**, minutes recorded and signed by all members | UGC 2018 cl. 5.1 VIII(c), cl. 5.3 |
| Interview letter windows | `posts.interview_letter_opening_date` / `closing_date` |
| Non-teaching interview weight **20% of the total**, added to Paper I + II | CRR Rule 11 III(g) — but see OQ-008 |
| Ratio of vacancies to candidates called **≤ 1:15** | CRR Rule 16 |

**cl. 5.3 is a hard constraint on the design, not a preference.** Because selection concludes the
same day, an interview may not be scheduled across days for the same committee sitting without a new
committee session, and **no post-committee objection window is possible** (M15).

## 2. Data

```
interview_sessions  id · post_id · committee_id
                    held_on · venue · start_time · slot_minutes
                    status enum(scheduled, in_progress, concluded)
interview_slots     id · interview_session_id · application_id NULL
                    sequence · scheduled_at
                    attended bool NULL · attended_at NULL
                    UNIQUE (interview_session_id, sequence)
                    UNIQUE (interview_session_id, application_id)
```

Interview letters are generated by M32; attendance feeds M14.

**Indexes:** `interview_slots(application_id)` · `interview_sessions(post_id, held_on)`.

## 3. Domain services

```
App\Domain\Interview\ScheduleSession::handle(Post, Committee, SessionData): InterviewSession
App\Domain\Interview\AllocateSlots::handle(InterviewSession, AllocationParams): SlotReport
App\Domain\Interview\RecordAttendance::handle(InterviewSlot, bool, User): void
App\Domain\Interview\ConcludeSession::handle(InterviewSession, User): void
```

**Invariants.**
- Only candidates on a **published shortlist** with the relevant gates `eligible` receive a slot.
- **`ConcludeSession` requires the committee to conclude the same day** (cl. 5.3). A session left
  open overnight must be re-constituted, and the system says so rather than allowing a silent
  carry-over.
- Slot allocation is **clash-free by construction** — the unique index on
  `(session, sequence)` and `(session, application)` makes a double booking impossible.
- **`RecordAttendance` sets the `interview` gate** (M34); it does not write a merit position.
- Interview letters generate **only inside the window**.

## 6. Authorisation

`InterviewPolicy` extends `ScopedPolicy` — `recruitment_admin` university-wide, `dean_office` within
their subtree for local posts. Candidates reach only their **own** letter, inside the window.

## 7. UI

**Session setup:** committee picker showing composition validity and quorum; date defaulted from the
committee's meeting date and **locked to it**.

**Slot board:** sequence, time, candidate, attendance. Drag to reorder before publication; frozen
after letters are generated, because a reordered slot after dispatch means a candidate arrives at the
wrong time.

**Attendance:** keyboard-first, ordered by slot, for a clerk at the board-room door.

**Conclusion** shows what is outstanding — unmarked attendance, unmet quorum, or a date mismatch —
before allowing the action.

## 8. Worked example

Post 884, Assistant Professor, 1 vacancy, 15 shortlisted.

1. Committee constituted for 22 May 2026, composition valid (M19).
2. Session scheduled 22 May, venue *Committee Room, Registrar's Office*, 20-minute slots. The date is
   locked to the committee meeting date.
3. `AllocateSlots` creates 15 slots, 09:30 to 14:30. Ratio 1:15 satisfied.
4. Interview letters generated on 12 May, inside the 10–20 May window (M32).
5. On the day: 13 attend, 2 absent. `RecordAttendance` sets `interview = eligible` for the 13,
   `rejected` for the 2 with remark *"did not attend"*.
6. The committee completes deliberation and all 5 members sign off. `ConcludeSession` succeeds
   because the conclusion date equals `held_on` — **cl. 5.3 satisfied**.
7. Had they tried to conclude on 23 May, it is refused: *"The selection process must conclude on the
   day of the meeting."* A new committee session is required.

## 9. Acceptance criteria

| ID | Given / When / Then |
|---|---|
| M13-R01 | Given a session date differing from the committee meeting date, when saved, then it is refused |
| M13-R02 | Given a conclusion attempted on a later day, when submitted, then it is refused, citing cl. 5.3 |
| M13-R03 | Given a candidate not on a published shortlist, when allocated a slot, then it is refused |
| M13-R04 | Given 1 vacancy, when 16 slots are allocated, then it is refused on the 1:15 ratio |
| M13-R05 | Given a duplicate slot sequence, when saved, then it fails on the unique index |
| M13-R06 | Given a candidate already slotted, when slotted again, then it fails |
| M13-R07 | Given attendance marked, when saved, then the `interview` gate is set with a remark |
| M13-R08 | Given an absent candidate, when recorded, then the gate is `rejected` with *"did not attend"* |
| M13-R09 | Given unmarked attendance, when concluding, then it is refused with the count |
| M13-R10 | Given quorum unmet, when concluding, then it is refused |
| M13-R11 | Given a letter request outside the window, when made, then it is refused with the dates |
| M13-R12 | Given letters generated, when slots are reordered, then it is refused |
